# Example

A movable `Player` node with an exported resource, a callable method and a signal.
Requires Swift 6.4 and Godot master (4.8 development) on macOS ARM64.

From the repository root:

```sh
tools/run example
```

Open `example/project.godot` in Godot and run the scene. Hold the right arrow to
move the green square. `tools/run example --configuration release` builds with
optimization. Restart Godot after rebuilding.

To start your own game, follow [getting started](../docs/GettingStarted.md).
